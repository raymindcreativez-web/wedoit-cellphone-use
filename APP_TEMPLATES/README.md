# APP_TEMPLATES

Reusable starting templates for AI-assisted application development.

Templates:

- SaaS_Template
- Mobile_App_Template
- Internal_Tool_Template
- Marketplace_Template

Usage:

1. Copy the desired template into a new project.
2. Complete PROJECT_CONTEXT.md.
3. Initialize APP_MEMORY.md.
4. Start Antigravity using MASTER_AI_INSTRUCTIONS.md.
